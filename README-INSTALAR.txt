ZAPFLOW AI - INSTALACAO
=======================

OPCAO A - Instalador automatico (Windows)
-----------------------------------------
1. Execute o arquivo: Instalar-ZapFlow.bat
2. Ele copia os arquivos e registra a extensao no Chrome
3. Reinicie o Chrome
4. Acesse: chrome://extensions e verifique se "ZapFlow AI" esta ativa
5. Abra web.whatsapp.com e clique no botao flutuante "ZF"
6. Login padrao: admin / admin123

OPCAO B - Instalacao manual (Qualquer PC)
-----------------------------------------
1. Extraia o ZapFlow-Extensao.zip em uma pasta
2. Abra o Chrome em: chrome://extensions
3. Ative o "Modo do desenvolvedor" (canto superior direito)
4. Clique em "Carregar sem compactacao"
5. Selecione a pasta extraída
6. A extensao ficara instalada enquanto o Chrome estiver aberto

USO DENTRO DO WHATSAPP WEB
--------------------------
- Abra web.whatsapp.com
- Botao flutuante "ZF" aparece no canto inferior esquerdo
- Clique para abrir o painel ERP (Dashboard padrao)
- Menu lateral: Dashboard, WhatsApp, CRM, Disparos, Funil, Catalogo, IA, etc.

ARQUIVOS
--------
- manifest.json
- whatsapp-panel.js (painel injetado no WhatsApp Web)
- popup.html, popup.js, popup.css (popup da extensao)
- content.js
- Instalar-ZapFlow.bat (instalador Windows)
